# Arabic style guide (Friday Arabic posts)

Read this before writing any Arabic caption or card. The aim: it reads like a Saudi finance professional wrote it in Arabic,
not like an English post that was translated.

## 1. Write it in Arabic, do not translate
- Start from the facts (numbers, sources, the two takeaways), not from an English draft. Build each sentence the Arabic way.
- Put the number or the fact first when it is the hook: "مليار دولار جمعتها..." reads better than "جمعت ... مليار دولار".
- Short sentences. One idea per line. Use و / لكن / لذلك to join, not long chains of commas.

## 2. Register
- Clear Modern Standard Arabic, the way Saudi business people write on LinkedIn (Argaam, Asharq Business tone).
- No flowery words, no religious openers, no "في عالم..." openers, no "ولا شك أن", no "من الجدير بالذكر".
- No harakat. Western digits (2026, 56%, 113). Currency: "مليار دولار", "563 مليون دولار".
- Write changes in words, never with a minus sign (a minus sign flips in right-to-left text): "تراجع 29%", "ارتفع 12%".

## 3. Translation phrases to avoid → use instead
| Avoid (sounds translated) | Use |
|---|---|
| أمران ألاحظهما / شيئان أخذتهما | ملاحظتان: / ما لفت نظري: |
| تحملان الرقم الإجمالي (carry the headline) | هما سبب ارتفاع الرقم الإجمالي |
| يضع عبئاً أكبر على | صار الحمل الأكبر على |
| انتظام ضخّها للاستثمارات | استمرارها في الاستثمار بوتيرة ثابتة |
| في نهاية اليوم / في نهاية المطاف | في النهاية / الخلاصة |
| يلعب دوراً مهماً | له أثر كبير على / يؤثر في |
| على الطاولة | مطروح |
| من دونهما يعود باقي السوق | لو استبعدناهما، يرجع باقي السوق |
| هل هذا يتطابق مع ما ترونه | هل هذا ما ترونه في صفقاتكم؟ |
| قم بـ / تم + مصدر (تم إطلاق) | فعل مباشر (أطلقت الشركة) |

## 4. Finance glossary (Saudi usage)
Keep the English term where Saudi professionals use it as is; otherwise the Arabic term.
| English | Write |
|---|---|
| Venture capital | رأس المال الجريء |
| Startups | الشركات الناشئة |
| Series A / B, seed | جولات Series A / جولة Series B / جولة البذرة (seed) |
| Mega round | صفقة كبرى / جولة كبرى |
| Deal count | عدد الصفقات |
| Fund manager | مدير الصندوق / مديرو الصناديق |
| Deploy capital | يستثمر / يضخ استثمارات |
| IPO | الطرح العام الأولي (IPO) |
| Listing on Tadawul | الإدراج في تداول |
| M&A | الاستحواذات والاندماجات |
| Private equity | الملكية الخاصة |
| Valuation | التقييم |
| Revenue / net profit | الإيرادات / صافي الربح |
| Year on year | مقارنة بالفترة نفسها من العام الماضي |
| 9M 2026 / Q3 2026 | الأشهر التسعة الأولى من 2026 / الربع الثالث 2026 |
| Sovereign wealth fund | صندوق الثروة السيادي |
| Brand names (MAGNiTT, PIF, HUMAIN, STV) | keep the usual form; PIF may be "صندوق الاستثمارات العامة" |

## 5. Structure (same as his English posts)
Hook number (1-2 lines) → short list of figures → "ملاحظتان:" with 2 numbered points → one line on what to watch →
one question to the reader → sources line "المصادر:" → hashtags: 2 Arabic + 1-2 English.

## 6. Final check (do all, every time)
1. Read every sentence and ask: would a Saudi analyst write this exact sentence? If it looks like word-for-word English, rewrite it.
2. Scan the table in section 3; none of the left-column phrases may appear.
3. No minus signs, no harakat, no Eastern digits, numbers match the sources exactly.
4. Humanizer pass in Arabic: cut filler, inflated words, forced lists of three, and closing one-liners.
5. Card text follows the same rules (short, no translated phrases).

## Example (target style)
مليار دولار جمعتها الشركات الناشئة السعودية في أول 9 أشهر من 2026.
لكن صفقتين فقط تمثلان 56% من هذا المبلغ.

ملاحظتان:
1. الرقم الإجمالي مرتفع بسبب جولتين بقيمة 563 مليون دولار. لو استبعدناهما، يرجع باقي السوق إلى مستوى الفترة نفسها من 2024.
2. التراجع الأكبر كان من المستثمرين الدوليين، لذلك صار الحمل الأكبر على الصناديق المحلية.
